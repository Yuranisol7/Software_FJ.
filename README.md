
# SISTEMA INTEGRAL DE GESTION - SOFTWARE FJ

## 1. Descripcion del proyecto

El proyecto Software FJ consiste en el desarrollo de un sistema integral para gestionar clientes, servicios y reservas mediante el lenguaje de programacion Python.

El sistema permite registrar clientes, administrar diferentes tipos de servicios, realizar reservas, calcular costos y controlar las operaciones mediante excepciones personalizadas.

## 2. Objetivo general

Desarrollar una aplicacion utilizando Programacion Orientada a Objetos que permita gestionar clientes, servicios y reservas de manera organizada, aplicando herencia, encapsulamiento, abstraccion, polimorfismo y manejo de excepciones.

## 3. Tecnologias utilizadas

- Python 3.
- Visual Studio Code.
- Programacion Orientada a Objetos.
- Git y GitHub.

## 4. Estructura del proyecto

- entidad_base.py: clase abstracta principal.
- excepciones.py: excepciones personalizadas.
- logger.py: registro de operaciones y errores.
- cliente.py: gestion y validacion de clientes.
- servicios.py: administracion de los tipos de servicios.
- reserva.py: creacion, confirmacion y cancelacion de reservas.
- sistema.py: administracion general del sistema.
- main.py: ejecucion y pruebas del programa.

## 5. Tipos de servicios

El sistema contempla tres modalidades:

1. Reserva de salas.
2. Alquiler de equipos tecnologicos.
3. Asesorias especializadas.

## 6. Principios de Programacion Orientada a Objetos

El proyecto aplica:

- Abstraccion.
- Encapsulamiento.
- Herencia.
- Polimorfismo.

Tambien implementa validaciones, excepciones personalizadas y registro de eventos.

## 7. Ejecucion del programa

Para ejecutar el sistema:

1. Abrir la carpeta del proyecto en Visual Studio Code.
2. Verificar que Python este instalado.
3. Abrir la terminal.
4. Ejecutar el siguiente comando:

   python main.py

## 8. Resultados esperados

El programa realiza diferentes pruebas para comprobar el registro de clientes, la creacion de servicios, la gestion de reservas, el calculo de costos y el control de errores.

## 9. Conclusion

El desarrollo del proyecto permite aplicar los conceptos fundamentales de la Programacion Orientada a Objetos mediante una solucion practica para la gestion de clientes, servicios y reservas.
